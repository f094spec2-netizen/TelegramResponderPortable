Telegram 自动回复可携版
========================

1. 将整个 TelegramResponderPortable 资料夹复制到 Windows 10/11 电脑。
2. 双击 TelegramResponder.exe。
3. 第一次启动会打开「账号与装置设定」：
   - 填写 Telegram API ID 与 API Hash。
   - 自订 TG 登入装置名称。
   - 点击「新增账号并登入」，输入手机号、验证码与需要时的两步验证密码。
   - 可加入多组账号，并选取目前要使用的账号。
4. 到「检测对话 ID」页读取目前账号的私聊，选择对象后加入回复名单。
5. 回到主画面设定随机间隔，然后点击「启动挂机」。

重要事项
--------
- 请复制整个资料夹，不要只复制 EXE；账号 session 与设定保存在同资料夹的 .state 与 .env。
- .env、.state 及其中的 .session 文件属于敏感登入资料，请勿上传或传给他人。
- 关闭控制视窗不会停止后台；请使用「停止挂机」。
- Windows SmartScreen 可能提示未知发行者，因为此 EXE 未使用商业代码签章。
- 本工具仅用于已授权的测试端点。
